# HOSPITAL RPM — сайт аттестации (автономная версия)

Работает на вашем компьютере или сервере, ничего не зависит от Claude.
Нужен только Node.js 18 или новее (https://nodejs.org). Ставить пакеты не нужно.

## Запуск
1. Распакуйте папку, откройте в ней терминал.
2. `node server.js`
3. Сайт: http://localhost:3000
   Админка: ссылка «Администрирование» внизу страницы.

Код администратора в репозитории НЕ хранится. Перед запуском задайте его одним из способов:
- создайте файл `data/admin-code.txt` и впишите туда свой код (от 8 символов), либо
- задайте переменную окружения ADMIN_CODE (так делают на хостингах).
Без кода сервер не запустится. Порт — в `config.json` (или переменная PORT).

## Как пользоваться
- Админка → «Коды допуска». Одна строка = один игрок:
  `Никнейм` — код создастся сам, или `Никнейм ; ваш_код` — свой код (от 6 символов).
- Код работает только вместе со своим никнеймом и только один раз.
- Для каждого кода автоматически подбирается свой набор из 15 вопросов.
- Там же список всех участников, фото паспорта, письменные ответы и кнопки «1 балл / 0 баллов».
- В папке уже лежат 20 готовых кодов (см. админку), их можно удалить.

## Файлы
- `questions.json` — вопросы (можно редактировать и добавлять; перезапустите сервер).
- `config.json` — порт, код админа, время теста (минуты), число вопросов в тесте.
- `data/db.json` — все коды и результаты. `data/photos/` — фото паспортов. Делайте копии этой папки.
- `public/index.html` — внешний вид сайта.

## Чтобы сайт видели другие люди
Запустите его на VPS или бесплатном хостинге с Node.js (Render, Railway и т.п.), либо дома с
туннелем (например, Cloudflare Tunnel). Хостинг только для статичных файлов (GitHub Pages, Netlify)
не подойдёт: нужен сервер, который хранит коды и ответы. Для публичного доступа лучше включить HTTPS.
Папка `data` должна сохраняться между перезапусками (на бесплатных хостингах подключите постоянный диск).
